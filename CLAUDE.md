## Грабли — прочитать обязательно

**Кэш браузера.** Стили и скрипты подключены с хвостом `?v=N`. Поменяли CSS или
JS — поднимите номер во всех HTML, иначе у заходивших раньше останется старая
версия. Владелец смотрит с телефона, там кэш особенно липкий.

**Ориентация фотографий.** `sips` при конвертации HEIC/JPG с айфона теряет метку
поворота, и снимок ложится на бок. **Проверять только на полном размере** — по
миниатюрам поворот не читается, на этом уже обожглись: выложили 11 снимков
боком. Лечится `Image.rotate(-90, expand=True)` в PIL.

**Пропорции кадров.** После поворота вертикальное фото не влезает в широкий
блок — обрежет полосой. В разметке есть варианты под вертикальные снимки:
карточки каталога `4:5`, блок «фото рядом с текстом» — класс `is-tall`.

**`pbcopy` портит кириллицу и эмодзи.** В терминале владельца `LANG` пустой.
Копировать только так:

```bash
LC_ALL=en_US.UTF-8 pbcopy < файл
```

Иначе в Telegram подписи приходят кашей вида «рЯФІ –Ч–∞—П–≤–Ї–∞». Наступали.

**`read -s -p` в zsh не работает.** У владельца zsh, там `-p` означает «читать из
сопроцесса», и пароль печатается на экран открытым текстом. Правильно:
`read -s "T?текст"`.

**Проверка Apps Script через curl.** С флагом `-L` бесполезна: редирект
превращает POST в GET, и приходит 405, хотя скрипт отработал. Смотреть первый
ответ без `-L`: **302 = принято**.

**Пуш.** Нужен увеличенный `http.postBuffer` — уже прописан в репозитории.
Без него GitHub рвёт соединение на пачке фотографий.

**Правка скрипта на Google.** После изменения кода обязательно «Развернуть» →
«Управление развёртываниями» → карандаш → версия **«Новая»**. Просто сохранить
мало — сайт продолжит работать со старой версией. И не создавать новое
развёртывание: адрес поменяется, придётся переписывать `config.js`.

**Проверка анимаций.** В браузерной панели Claude Code страница скрыта: события
скролла и часы CSS-анимаций не идут, движение оттуда не проверить. Xcode на
машине нет, симулятор iOS недоступен. Анимации проверяет только владелец.
